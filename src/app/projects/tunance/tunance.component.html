Challenges & Solutions

Custom Domain & DNS Configuration

Challenge: Connecting a purchased .pt domain to the hosting environment and ensuring proper DNS propagation.

Solution: Configured DNS A and CNAME records to point the domain to GitHub Pages, validated domain ownership, and ensured HTTPS activation.

Production Deployment

Challenge: Deploying the Angular production build correctly while maintaining routing and asset paths.

Solution: Generated optimized build using Angular CLI and configured base-href correctly to ensure compatibility with GitHub Pages static hosting.

Responsive Cross-Device Compatibility

Challenge: Ensuring consistent layout and usability across desktop, tablet, and mobile devices.

Solution: Implemented responsive design principles using CSS media queries and flexible layouts, testing across multiple screen sizes and browsers.
